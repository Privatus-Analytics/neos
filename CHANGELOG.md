# Changelog

## 1.0.0 - 2026-10-28

### Added
- First release.
- Adds the Privatus Analytics script to the head of every Neos page once a site ID is set.
- Settings for the site ID, modules, excluded paths, allowed domains, page change mode, manual page views and the script host.
- A mixin that adds a Site ID field and a Modules field to the site node in the inspector.
- Skips the Neos backend, so your own editing is not counted.
